# Dev Session — 2026-05-28

## Bug Fixes

### SVG assets not resolving (HomeView.vue)
`<v-img src="../assets/wiki.svg">` and `cCreator.svg` caused webpack "Module not found" errors.  
**Fix:** Changed static `src` to `:src="require('../assets/wiki.svg')"` on both `<v-img>` elements.  
**Why:** Vuetify's `<v-img>` is a component, not a native `<img>` tag. Vue-loader only auto-transforms `src` on native HTML elements. Using `require()` explicitly tells webpack to resolve the asset.

### Content hidden behind app bar
Pages were rendering under the fixed nav bar.  
**Fix:** Wrapped `<router-view>` in `<v-main>` in `App.vue`.  
**Why:** Vuetify's `<v-main>` automatically calculates and applies top padding to account for the app bar height + breadcrumb extension slot.

### Breadcrumb "Dnd" link led to empty page
Route `/dnd/2024/wiki/classes` produced breadcrumbs: Home → Dnd → 2024 → Wiki → Classes. `/dnd` has no route.  
**Fix:** Updated `breadcrumbs` computed in `App.vue` to skip namespace segments (`dnd`, `wod`) and apply friendly labels to edition segments.
```js
const SKIP = new Set(["dnd", "wod"]);
const LABELS = { "2024": "D&D 2024", "5e": "D&D 5e", "vtm": "Vampire: the Masquerade", ... };
```

### MDI v7 removed brand icons
After upgrading `@mdi/font` from 5.9.55 → 7.4.47:
- `mdi-discord` — removed in v7, no replacement
- `mdi-dragon` — not in v7

**Fixes:**
- `mdi-dragon` → `mdi-dice-d20` (confirmed in v7, thematically appropriate for D&D)
- `mdi-discord` → inline SVG in all usages

### Webpack stale cache after MDI upgrade
After `npm install @mdi/font@latest`, webpack couldn't find the CSS file even though it existed.  
**Fix:** `Remove-Item -Recurse -Force "node_modules/.cache"` then restart dev server.

## Architecture: Multi-System / Multi-Edition

### Decision
The site will support multiple TTRPG systems (D&D, World of Darkness, and future games), each with multiple editions or sub-games.

### Routing structure
```
/                     → Landing page (system selector)
/dnd/2024             → D&D 2024 home
/dnd/2024/wiki/...    → D&D 2024 wiki content
/dnd/5e               → D&D 5e home (future)
/wod/vtm              → Vampire: the Masquerade (future)
```

Legacy redirects added: `/wiki` and `/wiki/:pathMatch(.*)*` → `/dnd/2024/wiki/...`

### New files created

**`src/systems.js`**  
Central config for all game systems and their editions. Exports:
- `systems` — array of system objects (id, name, icon, accent colours, editions array)
- `dnd2024Nav` — nav items for D&D 2024 (used by App.vue)

**`src/components/SystemSelector.vue`**  
Game/edition picker shown on the landing page. Reads from `systems.js`. Available editions are clickable; unavailable editions show a "Soon" badge.

**`src/views/LandingView.vue`**  
New root landing page (`/`). Contains:
- Hero section with welcome text
- `<SystemSelector />`
- Site footer
